# Independent off-site watercourse references

F-2 creation and F-3 enhancement inputs accept and retain their own optional `offSiteReferenceNumber` string through the existing checked and unchecked schemas and `featuresFromInput`. Eager and streaming workbook parsers read F-2 AG and F-3 AT. F-3 retains this separately from `baseline.offSiteReferenceNumber`, which comes from F-1 AH; the baseline reference never substitutes for the enhancement reference. Numeric workbook labels, including zero, are converted to text without losing their value. API callers supply strings.

Checked validation requires a nonempty row reference when spatial risk is supplied (inherited from the baseline for F-3). `featuresFromInput` reports `Off-site reference required ▲` against `offSiteReferenceNumber` with the original sheet and input index. Missing and empty references fail that check. Excel tests literal empty cells, so whitespace-only strings count as content and are preserved, matching the existing baseline reference check. Trimming or rejecting such text is a separate editor input policy. Input types remain optional so unchecked callers can preserve incomplete rows; malformed reference types are rejected in both modes. The published JSON Schema exposes the independent string field in both input definitions. The existing eager/streaming checked parsers retain their fail-fast behavior.

Unchecked calculations retain unreferenced rows. Their raw delivered-unit number and Decimal companion are zero, while the separately calculated spatial-unit values remain available. This follows the workbook's independent formulas: F-2 AC checks AG, while AB calculates spatial units separately; F-3 AP checks its own AT, while AO calculates independently. A valid reference retains the ordinary delivery. This is a reference-specific contribution gate, not a rule that every diagnostic excludes every calculation.

The evidence is the existing static formula mapping for the supported version 4.1 `examples/less-simple.xlsm` workbook at source commit `1a2d9a55f8288e91a497ebf4a585452495008084`: F-2 AG is the off-site reference input used by AC, F-3 AT is independently editable and used by AP, and F-3 AM inherits spatial risk from F-1. No new live Excel recalculation was performed. The reference tests use an established Ditches creation or enhancement delivering 4 raw units and 2 spatial units at multiplier 0.5; omitting the row reference changes only the raw contribution to zero.

Consumers of checked schemas must supply the independent reference for valid off-site watercourse creation and enhancement rows. Consumers of unchecked schemas must use the returned raw and spatial values independently; recomputing one from the other would lose the workbook's reference gate. Intel should adopt the released library change before removing its raw-row reference recovery and duplicate reference checks. Broader timing, pathway and aggregate gates remain separate work. This change adds no public calculation or validation entrypoint.
